> **Design question:** What does the player do, repeatedly, and why do they keep doing it?
>
> **Time to complete:** 20–30 minutes
>
> **When to use:** After Worksheet 3. You need a defined core mechanic before you can map the loops around it.

---

## Instructions

Every game has three loop layers operating simultaneously. They're not sequential — they run in parallel, nested inside each other. The moment-to-moment loop drives action. The session loop provides structure. The long-term loop provides retention.

If any layer is missing, players will stop playing — even if the moment-to-moment feels great.

Fill in each layer independently, then check that they connect (the last step).

---

## The Three Loop Layers

```
┌─────────────────────────────────────────────────────────┐
│  LONG-TERM LOOP (hours → weeks → completion)            │
│  "Why do I come back tomorrow?"                         │
│  ┌─────────────────────────────────────────────────┐    │
│  │  SESSION LOOP (5 → 30 minutes)                  │    │
│  │  "Why do I keep playing this run/level?"        │    │
│  │  ┌─────────────────────────────────────────┐    │    │
│  │  │  MOMENT-TO-MOMENT LOOP (0 → 30 seconds) │    │    │
│  │  │  "Why did I just do that again?"         │    │    │
│  │  └─────────────────────────────────────────┘    │    │
│  └─────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────┘
```
