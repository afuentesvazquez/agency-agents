# Worksheet 8: Secondary Mechanics

> **Design question:** What supports the core mechanic, and what's just feature creep?
>
> **Time to complete:** 20 minutes
>
> **When to use:** After completing all Tier 1 worksheets. You need a clear core mechanic before you can correctly classify what's secondary.

---

## Instructions

List every mechanic or system you're considering for this game. Then evaluate each one against the core mechanic defined in Worksheet 3.

The goal is not to cut everything — it's to understand the relationship between each system and your core. A secondary mechanic that amplifies your core is essential. One that competes with it is probably feature creep.
