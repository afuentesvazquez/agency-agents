# Worksheet 1: Seed & Mandate

> **Design question:** What is this game and why does it need to exist?
>
> **Time to complete:** 15–20 minutes
>
> **When to use:** First. Before any other worksheet. If you can't complete this one, you don't have a concept yet — you have an idea.

---

## Instructions

Fill in every field. If a field is blank, that's a signal: you haven't made that decision yet. Unclear answers are normal on the first pass — write what you have, then pressure-test it.

The mandate (section 4) is the most important field. If you can't name 3–5 non-negotiables, you don't know what you're making.

---

## 1. Working Title

> A placeholder name that helps you refer to the project. It doesn't have to be good — it just has to be specific enough that you stop calling it "my game idea."

```
Working title: _______________________________________________
```

---

## 2. One-Sentence Description

> If you can't say what this game is in one sentence, you don't know what it is. No compound sentences. No "it's like X but also Y and then Z."
>
> Format: **"[Player] does [action] to [achieve goal] in [setting/context]."**

```
This game is: _________________________________________________

_____________________________________________________________
```

---

## 3. Core Fantasy

> What experience does the player *have* when this game is working perfectly? Not mechanics — emotion and identity. What does the player get to *feel* or *be*?
>
> Examples:
> - "The player feels like a brilliant tactician who sees three moves ahead."
> - "The player experiences the loneliness and wonder of being the last human alive."
> - "The player feels the satisfying momentum of a perfectly executed movement sequence."

```
The player gets to feel/be: ___________________________________

_____________________________________________________________

_____________________________________________________________
```

---

## 4. Mandate

> What must this game deliver to be worth building? These are non-negotiables — if the game ships without delivering these, it has failed regardless of what else it does.
>
> Write 3–5 mandates. Each one should be specific enough that you could test it with a playtest.

```
This game must:

1. ___________________________________________________________

2. ___________________________________________________________

3. ___________________________________________________________

4. (optional) _______________________________________________

5. (optional) _______________________________________________
```

---

## 5. Inspiration Sources

> What existing games, films, books, or other media directly informed this concept? Be specific — not genres, actual titles.
>
> For each source, note what it contributes (mechanic, tone, aesthetic, structure, etc.).

```
Source 1: ________________________  What it contributes: _____________________

Source 2: ________________________  What it contributes: _____________________

Source 3: ________________________  What it contributes: _____________________

Source 4: ________________________  What it contributes: _____________________
```

---

## 6. What This Is NOT

> Explicitly naming what this game avoids is as important as naming what it is. This prevents scope creep and clarifies your focus.
>
> Finish each sentence:

```
This game is NOT a ___________________________________________

This game will NOT have ______________________________________

This game is NOT trying to compete with _____________________

This game will NOT require the player to ____________________
```

---

## Completion Check

Before moving to Worksheet 2, confirm:

- [ ] My one-sentence description has no "and also" or "but then"
- [ ] My mandate has at least 3 specific, testable non-negotiables
- [ ] I can explain the core fantasy in one sentence without mentioning mechanics
- [ ] I know at least 2 specific inspiration sources and what I'm borrowing from each

If any box is unchecked, go back and sharpen that section before continuing.
