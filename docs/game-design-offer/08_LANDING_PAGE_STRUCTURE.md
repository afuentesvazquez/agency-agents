# Landing Page Structure

> Specialist: UX / IA Lead
> Status: DRAFT — pre-validation

---

## Page Architecture Overview

Single continuous scroll page. No tabs, no multi-page navigation. Mobile-first design (majority of traffic from social links on phones).

**Estimated total scroll depth:** 8-12 screen heights on mobile
**Target read time:** 3-5 minutes for a motivated buyer

---

## Section-by-Section Specification

### Section 1: Hero

| Attribute | Detail |
|-----------|--------|
| **Objective** | Stop the scroll. Name the problem. State the offer. |
| **Key message** | Your game idea is a hypothesis. This toolkit tests it. |
| **Content elements** | Headline, subheadline, primary CTA button, optional secondary CTA |
| **Proof surface** | None — hero is about the promise, not the proof |
| **Content density** | SHORT — 3 elements maximum above the fold |
| **Priority** | CRITICAL |
| **Notes** | Must work on mobile without scrolling. Headline must be readable at 18px+ on small screens. CTA must be thumb-reachable. Dark background, high-contrast text. |

**Hero hierarchy:**
1. Headline (largest text on page)
2. Subheadline (1-2 sentences, lighter weight)
3. CTA button ("Get the Toolkit" or "Test Your Concept")

---

### Section 2: Problem

| Attribute | Detail |
|-----------|--------|
| **Objective** | Make the buyer feel understood. Name the specific pain. |
| **Key message** | Most indie games fail at the concept stage, not in production. |
| **Content elements** | Section headline, 2-3 short paragraphs, bullet list of pain-point questions |
| **Proof surface** | Recognition — "That's exactly what happened to me" |
| **Content density** | MEDIUM — enough to create emotional resonance, not so much it feels preachy |
| **Priority** | CRITICAL |
| **Notes** | This section should create a "mirror moment." The buyer sees their own experience described. Use second person ("You have a game idea..."). Avoid lecturing. |

---

### Section 3: What You Get

| Attribute | Detail |
|-----------|--------|
| **Objective** | Show the product's contents clearly and concretely. |
| **Key message** | A sequenced toolkit of worksheets and frameworks for concept clarity. |
| **Content elements** | Section headline, 7 artifact cards (name + one-line description each), optional visual preview |
| **Proof surface** | Artifact quality — if the descriptions sound useful, the product feels useful |
| **Content density** | MEDIUM — one card per artifact, no lengthy descriptions |
| **Priority** | CRITICAL |
| **Notes** | Use a card or list layout. Each artifact should have: icon/number, name, one-sentence description. Consider showing a blurred/preview image of one worksheet to make the product tangible. |

---

### Section 4: Who This Is For

| Attribute | Detail |
|-----------|--------|
| **Objective** | Help the buyer self-qualify. Filter out wrong-fit visitors. |
| **Key message** | Built for people with a game idea and no design structure. |
| **Content elements** | "This is for you if..." list (4-5 items), "This is NOT for you if..." list (4-5 items) |
| **Proof surface** | Specificity — the more specific the qualification, the more the right buyer feels targeted |
| **Content density** | SHORT — two concise lists |
| **Priority** | IMPORTANT |
| **Notes** | The "NOT for you" list builds credibility. It shows you're not trying to sell to everyone. Use checkmarks and X marks for visual clarity. |

---

### Section 5: How It Works

| Attribute | Detail |
|-----------|--------|
| **Objective** | Show the user journey through the toolkit. Make the process feel structured and achievable. |
| **Key message** | Five phases. One weekend. A clear concept. |
| **Content elements** | 5 numbered steps with titles and one-sentence descriptions |
| **Proof surface** | Methodology — the structured process itself is proof of rigor |
| **Content density** | SHORT — 5 steps, one sentence each |
| **Priority** | IMPORTANT |
| **Notes** | Numbered steps create a sense of progression. Use a vertical or horizontal step layout. Each step = one phase of the concept clarity journey. This section should feel like a roadmap. |

---

### Section 6: Social Proof / Credibility

| Attribute | Detail |
|-----------|--------|
| **Objective** | Build trust despite having no testimonials at launch. |
| **Key message** | The methodology is sound. The frameworks are proven. |
| **Content elements** | At launch: worksheet preview image(s), methodology explanation, brief founder note |
| **Proof surface** | Product quality as proof — if the worksheet looks professional and thoughtful, the buyer trusts the product |
| **Content density** | MEDIUM — 1-2 visual previews + short founder note |
| **Priority** | IMPORTANT |
| **Notes** | This section evolves. At launch: artifact previews. After 5+ sales: buyer quotes. After 20+ sales: full testimonial cards. Plan for this section to grow. Consider a "Methodology" sub-header: "Built on professional game design frameworks: core loops, design pillars, mechanic specification, viability scoring." |

**Launch-day credibility approach:**
- Show 1-2 worksheet previews (Viability Scorecard is the most impressive)
- Short founder note: "I built this because I kept seeing the same problem..." (3-4 sentences, real name)
- Framework attribution: "Based on established game design methodology"
- No fake testimonials, no "as seen in," no manufactured authority

---

### Section 7: Pricing

| Attribute | Detail |
|-----------|--------|
| **Objective** | Present both tiers clearly. Make the decision easy. |
| **Key message** | Choose your depth: test the concept ($19) or build the full package ($39). |
| **Content elements** | Two pricing cards side by side (stacked on mobile), feature lists, CTA buttons, "Most Complete" badge on Tier 2 |
| **Proof surface** | Value density — the feature list should feel substantial for the price |
| **Content density** | MEDIUM — cards with feature lists |
| **Priority** | CRITICAL |
| **Notes** | Tier 2 should be visually highlighted (border, badge, slightly larger). Both cards must have individual CTA buttons. Feature lists should use checkmarks. "One-time purchase" must be visible on both cards. |

**Pricing card structure:**

### Section 8: FAQ

| Attribute | Detail |
|-----------|--------|
| **Objective** | Remove remaining objections. Answer practical questions. |
| **Key message** | Here's what you're wondering — answered directly. |
| **Content elements** | 8-10 Q&A pairs in accordion format |
| **Proof surface** | Transparency — honest answers build trust |
| **Content density** | MEDIUM — concise answers (2-3 sentences each) |
| **Priority** | IMPORTANT |
| **Notes** | Use collapsible/accordion format on mobile. Most important questions first. Include: "Can't I find this for free?" and "Do I need game design experience?" and "What format is the product?" These are the predicted top objections. |

---

### Section 9: Final CTA

| Attribute | Detail |
|-----------|--------|
| **Objective** | Convert the reader who scrolled to the bottom. Last push. |
| **Key message** | Your concept is a hypothesis. Run the test. |
| **Content elements** | Headline, 1-2 sentence body, two CTA buttons (both tiers) |
| **Proof surface** | Framing — the time-cost of NOT buying ("months of building the wrong thing") |
| **Content density** | SHORT — headline + one sentence + buttons |
| **Priority** | IMPORTANT |
| **Notes** | Mirror the hero structure but with a different angle. The hero says "here's the problem and the offer." The final CTA says "here's the cost of not acting." |

---

### Section 10: Footer

| Attribute | Detail |
|-----------|--------|
| **Objective** | Legal, contact, trust signals. |
| **Key message** | This is a real business. You can reach us. |
| **Content elements** | Product name, one-line description, "One-time purchase. Instant delivery. 14-day refund policy.", legal/terms link, contact email |
| **Proof surface** | Legitimacy — real email, real terms, refund policy visible |
| **Content density** | SHORT — minimal |
| **Priority** | NICE-TO-HAVE (but legally necessary) |
| **Notes** | Keep it minimal. Dark background, small text. Include refund policy link. Include contact email. |

## CTA Button Placement

| Location | CTA Type | Text |
|----------|----------|------|
| Hero (above fold) | Primary | "Get the Toolkit" or "Test Your Concept" |
| End of "What You Get" section | Secondary | "See Pricing" (anchor link to pricing section) |
| Pricing section | Primary (x2) | "Get the Concept Test" / "Get the Concept Pack" |
| Final CTA section | Primary (x2) | "Get the Concept Test — $19" / "Get the Full Pack — $39" |

**Total CTA touchpoints:** 4 locations, covering early/mid/late scroll positions.

## Mobile-First Hierarchy

| Priority | Mobile Behavior |
|----------|----------------|
| Hero headline | Must be readable without pinching. 24px+ minimum. |
| CTA buttons | Full-width on mobile. Thumb-reachable. |
| Pricing cards | Stack vertically (Tier 1 on top, Tier 2 below with badge) |
| FAQ | Accordion collapse (question visible, answer hidden until tapped) |
| Artifact list | Vertical list, not grid |
| Images | Full-width, optimized for mobile bandwidth |
| Body text | 16px minimum. Line height 1.5+. Max 75 characters per line. |

## Attention Budget Estimate

| Section | Est. time spent | % who reach this section |
|---------|----------------|--------------------------|
| Hero | 3-5 seconds | 100% |
| Problem | 15-30 seconds | 70% |
| What You Get | 20-40 seconds | 55% |
| Who It's For | 10-15 seconds | 45% |
| How It Works | 10-15 seconds | 40% |
| Credibility | 10-20 seconds | 35% |
| Pricing | 20-40 seconds | 30% |
| FAQ | 15-30 seconds | 20% |
| Final CTA | 5-10 seconds | 15% |

**Implication:** The hero and problem sections carry the heaviest load. If they don't hook, the rest doesn't matter.
